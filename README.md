# gradle/gradle-build-action

Configures Gradle for GitHub actions, caching state and generating a dependency graph via Dependency Submission.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/gradle/gradle-build-action](https://github.com/gradle/gradle-build-action).
